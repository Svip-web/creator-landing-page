# CREATOR

Окремий адаптивний сайт за матеріалами Google Docs та на основі візуального стилю попереднього сайту.

Публічні файли містяться у `dist/`. Папку можна розмістити на звичайному статичному хостингу.

`node build.mjs` формує HTML з локальної копії наданих текстів. `node preview.mjs` відкриває локальний сервер на порту 4318.

Перед відкриттям продажів потрібно додати підтверджені дату старту, ціни та посилання або інтеграцію приймання заявок. Зараз вибір тарифу відкриває інформаційне вікно; контакти не збираються, оплати й заявки не надсилаються.

Зміст програми збережено мовою оригіналу. Редакторський коментар у документі перед блоком 14 виключено з сайту. Стокові приклади з референсів не використовуються як фотографії менторів.
